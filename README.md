<h2>Problem Statement</h2>

<p>

The Kerala Floods of 2018 were among the most devastating natural disasters in India's history, causing widespread destruction to human life, infrastructure, agriculture, and public property. The available flood-related information is distributed across multiple datasets, including rainfall records, flood levels, damage reports, relief operations, and affected population data.

Analyzing these datasets individually makes it difficult to understand the complete disaster situation and identify the most affected areas.

Therefore, there is a need for an interactive dashboard that integrates all available data into one platform to support better decision-making, disaster monitoring, and efficient resource allocation.

</p>

</div>

<div class="card">

<h2>Solution</h2>

<p>

This project develops an interactive Power BI dashboard that combines all available Kerala Flood 2018 datasets into a single analytical platform.

The dashboard enables government authorities, disaster management teams, and researchers to:

</p>

<ul>

<li>Monitor rainfall trends.</li>

<li>Track flood severity and alert levels.</li>

<li>Analyze affected families and population.</li>

<li>Visualize infrastructure and agricultural damage.</li>

<li>Monitor relief camp operations.</li>

<li>Track rescue resources and emergency response.</li>

<li>Compare affected districts using interactive visuals.</li>

<li>Generate data-driven insights for disaster management.</li>

</ul>

</div>

<div class="card">

<h2>Solution Explanation</h2>

<ul>

<li><strong>Data Collection:</strong> Imported normalized Kerala Flood 2018 Excel dataset.</li>

<li><strong>Data Cleaning:</strong> Removed duplicate records, corrected missing values, and standardized data formats.</li>

<li><strong>Data Modeling:</strong> Established relationships between Weather, Damage, Relief, Main, and Location tables using Record ID.</li>

<li><strong>DAX Measures:</strong> Created calculated measures for rainfall, affected population, damage statistics, financial losses, and relief operations.</li>

<li><strong>Visualization:</strong> Designed multiple dashboards containing KPI Cards, Line Charts, Area Charts, Funnel Charts, Pie Charts, Maps, and Bar Charts.</li>

<li><strong>Interactivity:</strong> Added slicers and filters for District, Date, Alert Level, and Flood Level to enable dynamic analysis.</li>

<li><strong>Insights:</strong> Enabled users to identify high-risk regions, evaluate relief efforts, and understand disaster impact effectively.</li>

</ul>

</div>
